# java-racingcar-precourse

## 자동차 게임 기능 정리  

### 1. 입력 기능
- [X] 1.1 경주할 자동차 이름 입력받기 (쉼표로 구분)
    - 이름은 5자 이하
    - 사용자가 잘못된 입력 시 `IllegalArgumentException` 발생
- [X] 1.2 시도할 횟수 입력받기
    - 1 이상 정수 입력
    - 사용자가 잘못된 입력 시 `IllegalArgumentException` 발생

### 2. 게임 진행 기능
- [X] 2.1 0~9 랜덤값 중 4 이상이면 전진 or 아니라면 멈춤

### 3. 결과 계산 기능
- [X] 3.1 가장 많이 전진한 자동차가 우승하고, 공동우승도 가능. (쉼표로 구분하요 출력)
  
### 4.출력 기능
- [X] 4.1 각 시도 결과 출력
- [X] 4.2 최종 우승자 출력 (`최종 우승자 : pobi, jun`)
- [X] 4.3 입출력을 view 패키지에 따로 넣어서 객체분리
- [X] 4.4 각 시도마다 자동차 이름과 위치를 출력 (ex `이름 : ---` 형태)

### 5. Application에서 최종 호출
- [X] 구현 완료
